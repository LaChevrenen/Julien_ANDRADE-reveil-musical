# Réveil musical

Service qui réveille un utilisateur avec un morceau choisi selon le jour de la semaine et la météo, puis le notifie sur son canal préféré.

Architecture détaillée : [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Lancer

```
dotnet build
dotnet test
```

## Dépendances (licence et fraîcheur)

Aucun package n'est ajouté sans lecture préalable de sa licence dans le `.nuspec` du cache NuGet et vérification de la dernière version stable (`dotnet list package --outdated`). Tout copyleft est refusé.
